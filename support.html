Mac app: common questions

Where is my data stored?

On your Mac, inside the app’s sandbox (Application Support). Nothing is uploaded to us. Use Settings → Zip Backup to create a zip archive you can keep in Files, iCloud Drive, or another folder you choose.

How do I move my data to a new Mac?

Create a zip backup on the old Mac, copy it to the new one (for example through iCloud Drive or AirDrop), then restore it from Settings → Zip Backup.

Zip backups don’t include edit keys. If iCloud Keychain is on, the new Mac picks them up automatically. Otherwise, on the old Mac right-click each organization you edit, choose Edit Access… → Export Key File…, and drag those .rollingkey files onto the new Mac’s window.

Why is an organization read-only?

Someone shared it with you as a read-only copy, so you can review it but not change it. It shows an eye icon in the sidebar. To edit it, ask one of its editors for an edit key file (.rollingkey) or its edit password, then click Unlock Editing…. You can also drag the key file anywhere onto the main window.

How do I share an organization without letting people change it?

Right-click it and choose Export organization…, then Read-only copy. If the organization shows as Open in Settings → Access, choose Protect Editing… first. To let someone edit, send them an Editable copy, or use Edit Access… to export a key file or set an edit password.

I sent someone a new version and it won’t replace their copy

A read-only organization can only be replaced by a file its editor exported. Export a fresh copy from the Mac that edits the organization, and make sure nobody opened and re-saved the file in between. If the file was changed by hand, the app warns that it was altered after export.

I lost the edit key

The edit key lives in your Keychain and in any key files you exported. If it is gone everywhere (for example, a Mac was erased with iCloud Keychain off), nobody can edit that organization again, and we cannot recover it. You can still open and review it, and Duplicate… keeps the same edit protection. Editors should keep an exported key file somewhere safe.

What is “Restore from URL”?

An optional way to restore a zip backup from an HTTPS link you control, such as a Google Drive share link. Leave the field blank if you do not use it. The app has no default backup URL.

I forgot an organization’s password

A password-protected organization is saved encrypted with a key made from its password, and the password itself is never stored. We cannot recover or reset it. The password hint (if you set one) appears on the unlock screen. If the password is lost, restore an earlier backup made before the password was added.

Excel export

Forecast → Export to Excel offers column layout (Actual / Budget / Forecast side by side) or row layout (metric rows). Known expenses export the same either way.

Voice search asks for microphone access

The microphone is used only while you speak an account name to find it. You can deny access and still use the rest of the app, or change it later in System Settings → Privacy & Security.

iPad reader: common questions

What does Rolling Forecast Reports do?

It is a read-only iPad companion to the Mac app. It opens organizations created in Rolling Forecast so you can browse reports, charts, scorecards, and report packs, present them, and export them to PDF or PowerPoint.

How do I get my data onto the iPad?

Tap + in the Library and choose one of:

  • Import File — an organization export (.rollingorg.json) or a zip backup from the Mac app, from Files or iCloud Drive.
  • Import from Link — an HTTPS link to an export or backup, including Google Drive share links.
  • Link Backup Folder — the folder your Mac app saves backups into (for example in iCloud Drive). Use Refresh to load the newest backup.

Will changes on the iPad affect my Mac data?

No. The reader never writes back to the Mac app’s files. Edits you make to report packs on the iPad stay on the iPad, and the reader tells you when the Mac version of a pack has changed since you edited it.

A password-protected organization asks for its password

Enter the same password used on the Mac. The reader keeps the organization unlocked only until the app quits, and does not save the password.

How do I back up the reader?

Use Backup → Back Up Reader in the Library to save a zip of your imported snapshots and local pack edits, and Restore Reader Backup to bring it back. Deleting the app deletes its data.
